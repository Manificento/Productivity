# Модуль `progress`

Метка дорожки: `area:progress`. Задачи: `scripts/agent.sh next progress`.

- **Пишет в таблицы:** `xpEvents`. Остальные таблицы — **только чтение** через `db` из `src/core/db.ts` (прогресс считается по данным всех блоков, но не меняет их).
- **Читает:** все таблицы, цели дня (квесты строятся из них).
- **Суть модуля:** опыт и уровни → навыки по блокам и ежедневные квесты (SPEC 0.3, раздел 3 и 5.6). RPG-слой, как в Do It Now.
- **Цели дня:** `useDailyTargets(todayKey())` из `src/core/adaptation/useDailyTargets.ts` — только чтение. Своих правил адаптации в модуле нет.
- **Начисление:** одна запись `xpEvents` на выполненный квест (`source: quest`, `questId`, `amount`); уровень — чистая функция от суммы в `logic/`, в БД не хранится.
- **Навыки:** шесть (Дела, Тело, Сон, Питание, Ум, Покой); опыт блока течёт в свой навык (`logic/xp.ts`), бонус квеста — в навык квеста (`QUEST_SKILL`). `questId` = `focus | bedtime | meditation | habits | breathing`, одна запись на (день, квест). «Отбой до» оценивается по записи сна следующего утра, поэтому проверяются сегодня и вчера.
- **Окно начисления:** `useQuests` (на любой вкладке) проверяет последние 7 дней; бонус, однажды записанный, не отзывается, если запись потом удалили (решение: «один раз» — по задаче #122; пересмотреть — отдельной issue).
- **Дневной потолок (#224):** базовый опыт за день ≤ `DAILY_XP_CAP` (`logic/xp.ts`), для живых и импортированных записей (`Task.source`, `WorkoutLog.sourceId`) одинаково; живые идут первыми. Бонусы квестов вне потолка и за импорт не начисляются. «Перенесено из истории» считается из таблиц; разовое сообщение помнится в localStorage.
- Квест не засчитывается дважды: перед записью проверяй, нет ли уже события с тем же `questId` за этот день.
- **Навигация:** блок открывается через «Блоки» (#106). Пока у блока нет полезной функции, он помечен «скоро»
  (`comingSoon: true` в `index.ts`); с первой полезной функцией `comingSoon` убрать (у этого блока уже снят). `navOrder` не задавать — это
  закреплённая вкладка нижней панели (не больше трёх), закрепление вкладок — отдельная issue.

Структура (создавай папки по мере надобности):

```
index.ts        манифест AppModule — не меняй path без issue type:contract
logic/          чистые функции + *.test.ts рядом (без React и Dexie — проверяет npm run deps)
data/           чтение/запись своих таблиц, хуки на useLiveQuery
components/     компоненты модуля (+ *.test.tsx)
*Page.tsx       страница; вложенные маршруты — <Routes> внутри страницы
```

Нельзя: импортировать `src/modules/<другой>/`, менять `src/core`, `src/ui`, `src/app`, добавлять зависимости.
