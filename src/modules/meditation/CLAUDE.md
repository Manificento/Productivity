# Модуль `meditation`

Метка дорожки: `area:meditation`. Задачи: `scripts/agent.sh next meditation`.

- **Пишет в таблицы:** `meditationSessions`. Остальные таблицы — только чтение через `db` из `src/core/db.ts`.
- **Читает:** цели дня (`meditationMin`, позже `meditationKind`).
- **Суть модуля:** таймер и дыхание (`4-7-8`, `box`) → библиотека сессий и план по фазам → аудио (P2, нужен контент) (SPEC 0.3, раздел 3 и 5.6).
- **Цели дня:** `useDailyTargets(todayKey())` из `src/core/adaptation/useDailyTargets.ts` — только чтение. Своих правил адаптации в модуле нет.
- **Сессия** пишется один раз по завершении или остановке (`completed: false`), `date` — локальный день начала (`toDateKey(startedAt)`).
- **Таймер** — `performance.now()` / `Date.now()` с фиксированным временем в тестах; сигнал конца — вибрация + короткий сгенерированный тон Web Audio (владелец разрешил, #186); аудиофайлов и записи нет.
- **Навигация:** блок открывается через «Блоки» (#106). Пока у блока нет полезной функции, он помечен «скоро»
  (`comingSoon: true` в `index.ts`); с первой полезной функцией `comingSoon` убрать. `navOrder` не задавать — это
  закреплённая вкладка нижней панели (не больше трёх), закрепление вкладок — отдельная issue.

Структура (создавай папки по мере надобности):

```
index.ts        манифест AppModule — не меняй path без issue type:contract
logic/          чистые функции + *.test.ts рядом (без React и Dexie — проверяет npm run deps)
data/           чтение/запись своих таблиц, хуки на useLiveQuery
components/     компоненты модуля (+ *.test.tsx)
*Page.tsx       страница; вложенные маршруты — <Routes> внутри страницы
```

Нельзя: импортировать `src/modules/<другой>/`, менять `src/core`, `src/ui`, `src/app`, добавлять зависимости.
