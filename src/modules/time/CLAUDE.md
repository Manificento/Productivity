# Модуль `time`

Метка дорожки: `area:time`. Задачи: `scripts/agent.sh next time`.

- **Пишет в таблицы:** `timeCategories`, `timeEntries`, `settings` (только ключи `time.*`; настройки Pomodoro — `time.pomodoro`). Остальные таблицы — только чтение через `db` из `src/core/db.ts`.
- **Суть модуля:** учёт времени по категориям, единственный активный таймер, Pomodoro с привязкой к задачам, баланс за день/неделю.
- **Цели дня:** `useDailyTargets(todayKey())` из `src/core/adaptation/useDailyTargets.ts` — только чтение.

Структура (создавай папки по мере надобности):

```
index.ts        манифест AppModule — не меняй path без issue type:contract
logic/          чистые функции + *.test.ts рядом (без React и Dexie — проверяет npm run deps)
data/           чтение/запись своих таблиц, хуки на useLiveQuery
components/     компоненты модуля (+ *.test.tsx)
*Page.tsx       страница; вложенные маршруты — <Routes> внутри страницы
```

Нельзя: импортировать `src/modules/<другой>/`, менять `src/core`, `src/ui`, `src/app`, добавлять зависимости.

## Решения модуля

- **Pomodoro: длительности — в `settings` под ключом `time.pomodoro`** (`data/pomodoroStore.ts`), поэтому попадают в
  резервную копию и переезжают на новое устройство (#101). Старое значение из `localStorage`
  (`lifeos.time.pomodoro.settings`) при первом открытии переносится в `settings`, старый ключ удаляется.
  Рантайм подписан на ключ через `liveQuery`: импорт копии меняет длительности без перезагрузки.
  **Состояние таймера остаётся в `localStorage`** (`lifeos.time.pomodoro.state`) — это данные устройства.
- **`settings` `time.pomodoro.running`** = `{ phase: 'work'|'shortBreak'|'longBreak', startedAt, endsAt }` (мс, epoch) —
  зеркало идущей фазы для других экранов (#68). Пишет `pomodoroRuntime.commit` (старт, смена фазы, стоп) и обработчик
  `storage` (другая вкладка); когда таймер не идёт — ключ удалён. Читать можно всем, писать — только `time`.
  Читатель считает сессию неидущей, если `endsAt <= now` (приложение могло быть закрыто).
- **Таймер Pomodoro — один на страницу** (`components/pomodoroRuntime.ts`): его держит `PomodoroBackground`
  (`Background` в манифесте, оболочка монтирует на всех страницах, #59), а `usePomodoro` на экранах «Времени»
  читает тот же таймер через `useSyncExternalStore`. Поэтому сессия записывается и сигналит и в других модулях.
  Закрытое приложение догоняет при открытии (по меткам времени), сигнал — только если фаза кончилась < 2 мин назад.
  `pomodoroRuntime` лежит в `components/`, хотя это не React: это императивная оболочка таймера для хука и фона.
  Две открытые вкладки тикают обе: записи идемпотентны (по времени начала), но сигнал изредка может прозвучать в обеих.
- Фокус-сессия пишется в `timeEntries` **до** смены состояния: ошибка записи не теряет сессию, следующий тик повторяет.
- Одновременно идёт один «счётчик»: старт фокуса останавливает таймер учёта и наоборот.
- **Баланс: изменение к прошлой неделе — к тому же моменту** (чт 18:00 ↔ прошлый чт 18:00), чтобы неполная неделя
  не сравнивалась с полной. Признак «прошлая неделя есть» — по всей прошлой неделе. Недели — календарные (`addDays`), не 168 ч.
- **Норма фокус-сессий (#16):** сессией считается запись `source: pomodoro` дня от 10 минут (`MIN_FOCUS_SESSION_MS`),
  не зависит от текущей длительности фокуса. При `focusPomodoros = 0` показываются все `reasons` дня.
