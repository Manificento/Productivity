# Модуль `cognition`

Метка дорожки: `area:cognition`. Задачи: `scripts/agent.sh next cognition`.

- **Пишет в таблицы:** `cognitiveTests` (тесты: PVT), `mindSessions` (тренажёры ума: n-back, Струп, таблицы Шульте — SPEC 0.3, раздел 5.6). Остальные — только чтение через `db`.
- **Суть модуля:** короткие объективные когнитивные тесты. Первый — PVT (тест психомоторной бдительности,
  1 минута): реакция на стимул через случайные интервалы. Результаты — сигнал «достаточно ли сна и отдыха»
  для будущей персонализации (`docs/product-decisions.md`). Позже здесь вырастет блок нейротренажёров.
- **Вход из утреннего потока:** маршрут `/cognition/pvt?return=<путь>` — после теста вернуть пользователя по `return`.
  Модуль `today` ссылается на этот маршрут, а не импортирует компоненты.
- **Тайминг:** только `performance.now()` и `requestAnimationFrame`, никаких `setInterval` для измерения реакции.
  Логика подсчёта (медиана, пропуски > 500 мс, фальстарты < 100 мс) — чистые функции в `logic/` с тестами.

Структура и запреты — как в других модулях: `logic/` чистая, `data/` — Dexie, `components/` — UI,
без импортов других модулей и без правок `src/core`, `src/ui`, `src/app`.
