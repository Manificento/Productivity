# План сборки MVP облачными сессиями

## Схема

```
                ┌──────────────── каркас (готов) ────────────────┐
                │ core: типы, БД, даты, движок адаптации, бэкап   │
                │ app: роутинг, навигация · ui: мини-кит · CI     │
                └────────────────────────┬────────────────────────┘
       ┌────────────────┬────────────────┼────────────────┐
  Сессия A          Сессия B         Сессия C          Сессия D        ← параллельно, ночью
  tasks             habits + time    health            today (адаптация)
       └────────────────┴────────────────┼────────────────┘
                                  Сессия E — интеграция          ← утром, после всех PR
                         слияние PR, запросы контракта, проверка на 360 px
```

Каждая сессия пишет только в свою папку и свои таблицы (см. `CLAUDE.md`), поэтому четыре сессии
не конфликтуют. Связь между модулями — через общую БД и `useDailyTargets()`.

## Сессии

| Сессия | Промпт | Модули | Ключевой результат |
|---|---|---|---|
| A | `docs/prompts/session-A-tasks.md` | `tasks` | задачи, проекты, повторы, быстрый ввод на русском |
| B | `docs/prompts/session-B-habits-time.md` | `habits`, `time` | привычки и серии, учёт времени, Pomodoro |
| C | `docs/prompts/session-C-health.md` | `health` | сон, еда (Open Food Facts), тренировки |
| D | `docs/prompts/session-D-today.md` | `today` | события, чек-ин, экран «Сегодня», базовый режим, инсайты |
| E | `docs/prompts/session-E-integration.md` | всё | слияние, контракт, полировка, деплой |

## Как запускать

1. В claude.ai/code открой новую облачную сессию на этом репозитории, вставь текст промпта
   (или напиши: «Выполни docs/prompts/session-A-tasks.md»). Повтори для B, C, D — четыре вкладки.
2. Сессии работают сами; ноутбук можно закрыть. Утром у каждой будет PR.
3. Запусти сессию E: она сливает PR по очереди и чинит то, что сломалось на стыках.

## Порядок слияния

D → A → B → C. Адаптация первой, потому что её виджеты читают данные остальных модулей,
а остальные — только её цели. Если два PR трогают один файл вне своих папок — это нарушение
правил; интеграционная сессия переносит изменение в запрос контракта.

## Бюджет

Следи за счётчиком кредита на claude.ai/code. Если кредит заканчивается раньше, чем сессии, —
приоритет: D (уникальная ценность) и A (основа продуктивности); B и C можно доделать позже.
