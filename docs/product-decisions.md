## Стратегия

| Вопрос           | Решение                                                                                                           |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| Цель             | Продукт / стартап для других людей, не личный инструмент                                                          |
| Первая аудитория | Люди в саморазвитии, которые уже трекают себя (MacroFactor, Todoist, Sleep Cycle, носимые устройства)             |
| Главная ценность | Слой адаптации + инсайты между блоками; видение — супер-приложение для всех этапов жизни                          |

| Монетизация      | Freemium: трекеры и ограниченные инсайты/персонализация бесплатно, полная система по подписке                     |

## Путь продукта

Уточнено решением от 4 ноября (вечер): этапы идут как вехи одного кода, а не как смена платформы.

1. **Веб (PWA), вехи M1–M6** — все блоки, работающие без фоновых датчиков.
2. **Натив через Capacitor, веха M7** — будильник, трекинг сна по датчикам, уведомления, Health Connect / HealthKit.
3. **Облако и SaaS, веха M8** — аккаунты, синхронизация, аналитика, freemium, затем AI-коуч.
4. **Собственный автоматический трекинг** (сон по датчикам телефона) — R&D внутри M7.

**Критерий публикации в сторах:** месяц ежедневного использования владельцем с реальным экзаменом →
5–10 знакомых из аудитории пользуются 2 недели → если **≥ половины продолжают** (выясняется созвонами,
аналитики нет) — публикуем. Работа над нативной оболочкой этого критерия не ждёт.

## Опыт пользователя

- **Холодный старт:** онбординг спрашивает ближайшее событие и сразу показывает план на 10 дней;
  импорт истории из других приложений (когда будут образцы файлов).
- **Ввод данных ≤ 3 минут в день:** утренний поток «сон → чек-ин → тест внимания»; еда и тренировки — по желанию.

## Адаптация и персонализация

- **Источник правил:** научные правила по умолчанию + персонализация по данным + ручная настройка.
- **Эластичные границы (байесовский подход):** научная норма — априорное распределение. При малом объёме данных
  предложения не выходят за научный диапазон; при сильных доказательствах индивидуальности граница сдвигается
  (например, человеку действительно хватает меньше сна).
- **Автономия:** приложение предлагает изменение с объяснением и числом дней данных, **человек подтверждает**.
- **Мера «достаточно»:** все четыре сигнала — самооценка (чек-ин), поведение (задачи, фокус, привычки),
  объективный тест внимания (PVT), результаты событий (баллы экзаменов).

## Данные

- Local-first на всех платформах: данные на устройстве; облако (M8) — копия и синхронизация поверх, не замена.
- Продукт: **облако** (аналитика, AI-коуч, модели на данных всех пользователей).
  У всех записей уже есть `id`, `createdAt`, `updatedAt` для будущей синхронизации.

## Открытые вопросы

- Математика эластичных границ: модель, априорные распределения по метрикам, порог доказательств, объединение 4 сигналов.
- Юридика облачного хранения данных о здоровье (согласие, законы о персональных данных KZ, GDPR) — до облачного этапа (ADR-0009, веха M8).
- Точная граница freemium.
- Импорт: нужны реальные файлы экспорта Todoist / Sleep Cycle.
