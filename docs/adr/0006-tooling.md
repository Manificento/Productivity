# 0006. Выбор инструментов

Статус: принято · 2026-11-04

| Задача    | Выбор                                               | Почему                                                                                |
| --------- | --------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Сборка    | Vite                                                | быстрый dev-сервер, PWA-плагин, стандарт для SPA                                      |
| UI        | React 19 + TypeScript strict                        | крупнейшая экосистема — агенты пишут на нём надёжнее всего                            |
| Стили     | Tailwind v4                                         | стили рядом с разметкой, тёмная тема через `dark:`, нет конфликтов CSS между модулями |
| Данные    | Dexie + `dexie-react-hooks`                         | удобная обёртка над IndexedDB, живые запросы, миграции версиями                       |
| Даты      | date-fns                                            | чистые функции, локальное время; дни — только `DateKey` из `core/dates.ts`            |
| Валидация | zod                                                 | проверка данных на границах (импорт файлов, ответы Open Food Facts)                   |
| Маршруты  | react-router `HashRouter`                           | работает на любом статическом хостинге без настройки                                  |
| PWA       | vite-plugin-pwa (Workbox)                           | офлайн и установка «из коробки»                                                       |
| Тесты     | Vitest, Testing Library, fake-indexeddb, Playwright | см. ADR-0004                                                                          |
| Качество  | Prettier, oxlint, dependency-cruiser, coverage v8   | формат, линт, границы модулей, порог покрытия                                         |

**TypeScript закреплён на 6.x**: 7.x (нативный компилятор) пока не поддерживается API-зависимыми
инструментами (dependency-cruiser). Перейти на 7, когда инструменты добавят поддержку.

Новые зависимости добавляются только если без них нельзя; причина пишется в описании PR.
