# 0001. Local-first PWA без бэкенда в MVP

Статус: принято · 2026-11-04

## Контекст

Нужен MVP, которым можно пользоваться на телефоне и ноутбуке уже на этой неделе. Владелец не пишет
код руками, бюджет на инфраструктуру — ноль. Нативные приложения требуют сторов и сборок под две ОС.

## Решение

- Прогрессивное веб-приложение (PWA): ставится на домашний экран, работает офлайн через service worker.
- Данные хранятся в IndexedDB через Dexie. Сервера, аккаунтов и синхронизации нет.
- Защита от потери данных — экспорт/импорт JSON (`core/backup.ts`).
- Маршрутизация через `HashRouter`, сборка с `base: './'` — работает на любом статическом хостинге.

## Последствия

- ✅ Бесплатный хостинг (Cloudflare Pages, Netlify), мгновенный деплой, приватность по умолчанию.
- ✅ Все записи имеют `id`, `createdAt`, `updatedAt` — синхронизацию можно добавить позже без миграции данных.
- ❌ Нет синхронизации между устройствами (P2: бэкенд).
- ❌ Нет фонового доступа к датчикам и надёжного будильника — трекинг сна и «Alarmy» отложены до нативной версии.
- ❌ Уведомления на iOS ограничены.
