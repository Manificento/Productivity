# Сессия B — модули «Привычки» и «Время»

Ты строишь модули `habits` и `time` приложения LifeOS. Работай автономно до конца: владелец спит.
Неясное решай сам и записывай решения в `docs/progress/habits.md` и `docs/progress/time.md`.

## Сначала прочитай
`CLAUDE.md`, `docs/SPEC.md`, `src/core/types.ts` (Habit, HabitLog, TimeCategory, TimeEntry, Task),
`src/core/db.ts`, `src/core/adaptation/types.ts`, `src/ui/index.tsx`, `src/modules/habits/`, `src/modules/time/`.

## Твоя зона
Пиши только в `src/modules/habits/**`, `src/modules/time/**` и их файлы в `docs/progress/`.
Таблицы для записи: `habits`, `habitLogs`, `timeCategories`, `timeEntries`. Таблицу `tasks` — только читать.

## Привычки
1. Чистая логика + тесты: «запланирована ли привычка на день» для `daily`, `weekdays`, `timesPerWeek`;
   текущая и лучшая серия (для `timesPerWeek` — серия недель с выполненной нормой); процент за 7/30 дней.
   Неделя начинается с понедельника.
2. Интерфейс: список привычек на сегодня с большой кнопкой-отметкой (повторный тап снимает отметку);
   серия 🔥N; редактор (название, расписание, цвет, архив); календарная сетка за 5 недель на экране привычки.
3. Стартовый набор при первом запуске (если таблица пуста — предложить, не создавать молча):
   «Медитация», «Чтение 20 мин», «Английский», «Тренировка», «Отбой вовремя».

## Время
1. Чистая логика + тесты: длительность записи, итог по категориям за день и неделю, наложения
   (новый таймер останавливает текущий — одновременно идёт максимум один), записи через полночь
   делятся по дням для отчётов.
2. Таймер: выбор категории, старт/стоп, показ идущего таймера в шапке экрана; восстановление после
   перезагрузки страницы (запись с пустым `end`).
3. **Pomodoro**: 25/5 по умолчанию, длинный перерыв 15 мин после 4 сессий, всё настраивается
   (храни в записи категории или своём поле, не в чужих таблицах). Привязка к задаче (выбор из
   невыполненных задач). Каждая завершённая сессия → `TimeEntry` с `source: 'pomodoro'` и `taskId`.
   Таймер считает по меткам времени, а не по `setInterval`, чтобы не врать в фоне.
   Звук/вибрация по окончанию, если разрешено.
4. «Баланс»: столбцы по категориям за день и за неделю, сравнение с прошлой неделей.
5. **Адаптация**: на экране Pomodoro покажи «фокус-сессий сегодня: X из `focusPomodoros`» из
   `useDailyTargets(todayKey())`; если есть `focusProjectId` — предлагай задачи этого проекта первыми.
6. Стартовые категории (с подтверждением): Учёба, Работа, Спорт, Отдых, Быт, Сон.
