# Сессия C — модуль «Здоровье» (сон, еда, тренировки)

Ты строишь модуль `health` приложения LifeOS. Работай автономно до конца: владелец спит.
Неясное решай сам и записывай решения в `docs/progress/health.md`.

## Сначала прочитай
`CLAUDE.md`, `docs/SPEC.md`, `src/core/types.ts` (SleepLog, Food, MealLog, WorkoutLog),
`src/core/db.ts`, `src/core/adaptation/types.ts`, `src/ui/index.tsx`, `src/modules/health/`.

## Твоя зона
Пиши только в `src/modules/health/**` и `docs/progress/health.md`.
Таблицы для записи: `sleepLogs`, `foods`, `mealLogs`, `workoutLogs`.

Внутри модуля сделай вкладки «Сон / Еда / Тренировки» (вложенные маршруты под `/health/*`).

## Сон
1. Логика + тесты: длительность (отбой вечером, подъём утром — через полночь), `date` = день подъёма,
   средние за 7 дней, отклонение отбоя от цели.
2. Интерфейс: быстрый ввод «лёг / встал / качество 1–5» (по умолчанию — прошлая ночь); график за 14 дней
   (простые SVG-столбцы, без тяжёлых библиотек).
3. **Адаптация**: покажи целевые `sleepHours` и `bedtime` из `useDailyTargets(todayKey())` и
   разницу с фактом.

## Еда
1. Логика + тесты: КБЖУ приёма и дня (значения в `Food` — на 100 г), итоги по приёмам пищи.
2. Поиск продуктов: сначала свои (`foods`), затем Open Food Facts —
   `https://world.openfoodfacts.org/cgi/search.pl?search_terms=<q>&search_simple=1&json=1&page_size=20&fields=code,product_name,product_name_ru,nutriments`.
   Бери `energy-kcal_100g`, `proteins_100g`, `fat_100g`, `carbohydrates_100g`; пропускай продукты без калорий.
   Выбранный продукт кешируй в `foods` (`source: 'openfoodfacts'`, `externalId` = code) — потом работает офлайн.
   Сеть недоступна → понятное сообщение и предложение создать свой продукт. Дебаунс 400 мс.
   В тестах `fetch` мокается — настоящих запросов в тестах нет.
3. Интерфейс: день с приёмами пищи, добавление продукта с граммами, свой продукт, недавние продукты
   для быстрого повтора, итог КБЖУ за день.
4. **Адаптация**: если `noNewFoods` — при добавлении продукта, которого раньше не было в журнале,
   показывай мягкое предупреждение; покажи отсечку кофеина `caffeineCutoff`.

## Тренировки
1. Логика + тесты: недельный объём (минуты, число тренировок), средний RPE.
2. Интерфейс: запись (тип из списка + свой, длительность, RPE 1–10, упражнения с подходами — опционально),
   история, повтор прошлой тренировки одной кнопкой.
3. **Адаптация**: покажи `maxWorkoutIntensity` на сегодня; если выбранный RPE выше допустимого
   (`rest` → 0, `light` ≤ 4, `moderate` ≤ 6, `hard` — любой) — предупреждение с причиной из `reasons`.

`npm run check` зелёный; `docs/progress/health.md` заполнен; push; PR в `main` с чек-листом.
