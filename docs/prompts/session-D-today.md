# Сессия D — слой адаптации и экран «Сегодня»

Ты строишь главную уникальную часть LifeOS: слой адаптации. Работай автономно до конца: владелец спит.
Неясное решай сам и записывай решения в `docs/progress/today.md`.

## Сначала прочитай
`CLAUDE.md`, `docs/SPEC.md` (особенно раздел 5), весь `src/core/` (типы, БД, движок
`src/core/adaptation/` и его тесты), `src/ui/index.tsx`, `src/modules/today/`.

## Твоя зона
- `src/modules/today/**` и `docs/progress/today.md`;
- `src/core/adaptation/**` — ты владелец движка. Можно **добавлять** правила и поля `DailyTargets`;
  нельзя переименовывать или удалять существующие поля (их уже читают другие модули).
  Каждое новое правило — с тестами.
- Таблицы для записи: `lifeEvents`, `checkIns`, `settings` с ключами `adaptation.*`. Остальные — только читать.

## Что сделать (по порядку)

1. **События** (`/today/events`): список, создание и редактирование `LifeEvent` (название, тип, дата,
   время, важность 1–3, связанный проект из `projects`, дни подготовки, по умолчанию 7), удаление
   с подтверждением. На карточке события — таймлайн фаз (подготовка → разгрузка → событие →
   восстановление) с текущей позицией.
2. **Чек-ин дня**: энергия 1–5, фокус 1–5, заметка; одна запись на день (`checkIns.date` уникален —
   обновляй существующую). Карточка на «Сегодня», пока чек-ин не сделан.
3. **Экран «Сегодня»** (главный экран, mobile-first). Сверху вниз:
   - активное событие с обратным отсчётом («IELTS через 3 дня») и фазой;
   - `TargetsCard` (уже есть) с причинами;
   - задачи на сегодня из таблицы `tasks` (чтение) с полосой «план X / ёмкость Y мин», фокус-проект наверху;
     отметка выполнения прямо здесь — **нельзя**, это запись в чужую таблицу: дай ссылку на `/tasks`;
   - привычки на сегодня (чтение `habits`/`habitLogs`) — прогресс «3 из 5» и ссылка на `/habits`;
   - идущий таймер или фокус-сессии сегодня из `timeEntries` (чтение);
   - сон прошлой ночи и тренировка сегодня (чтение `sleepLogs`, `workoutLogs`) против целей.
   Пустые данные → короткая подсказка со ссылкой на нужный модуль, а не пустая карточка.
4. **Базовый режим** (`/today/baseline`): редактор `Baseline` (ёмкость дня, сон, отбой, интенсивность,
   Pomodoro, медитация, кофеин) → `settings` с ключом `adaptation.baseline`. Кнопка «сбросить к умолчаниям».
5. **Новые правила движка** (с тестами): 
   - два события в окне 3 дней друг от друга → правило «перегрузка»: ёмкость −10%, причина в `reasons`;
   - 3 дня подряд сна < 6.5 ч → отбой на 30 мин раньше;
   - тренировка `hard` вчера → сегодня не выше `moderate`.
   Для них расширь `AdaptationContext` и `loadDailyTargets` (добавляя поля, не меняя старые).
6. **Инсайты (P1)** (`/today/insights`): за 14–30 дней — связь «часы сна ↔ выполненные задачи следующего
   дня», «сон ↔ фокус-минуты», «тренировка ↔ энергия в чек-ине». Чистые функции с тестами
   (корреляция Пирсона + число дней данных; при < 7 точках пиши «мало данных», а не выдумывай вывод).
   Отображение — простые SVG-диаграммы рассеяния и фраза-вывод с оговоркой «связь, не причина».
7. **Предпросмотр**: на экране события — «как изменятся следующие 10 дней»: таблица целей по дням
   через `computeDailyTargets` (это очень наглядно показывает ценность продукта).

## Готово, когда
`npm run check` зелёный; тесты на каждое правило и функцию инсайтов; `docs/progress/today.md`
заполнен; push; PR в `main` с чек-листом.
