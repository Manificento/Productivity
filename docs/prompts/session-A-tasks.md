# Сессия A — модуль «Задачи»

Ты строишь модуль `tasks` приложения LifeOS. Работай автономно до конца: владелец спит и
ответить на вопросы не сможет. Если что-то неясно — прими разумное решение и запиши его в
`docs/progress/tasks.md`.

## Сначала прочитай
`CLAUDE.md`, `docs/SPEC.md` (разделы 3–6), `src/core/types.ts` (Task, Project, Recurrence),
`src/core/db.ts`, `src/core/adaptation/types.ts` (DailyTargets), `src/ui/index.tsx`, `src/modules/tasks/`.

## Твоя зона
Пиши только в `src/modules/tasks/**` и `docs/progress/tasks.md`. Пиши только в таблицы `projects`, `tasks`.

## Что сделать (по порядку, коммить после каждого пункта)

1. **Чистая логика + тесты** (`logic/*.ts`): фильтры «Сегодня», «Просрочено», «Предстоящие»,
   «Входящие» (без срока), по проекту, по тегу; сортировка (просроченные → приоритет → время);
   выполнение повторяющейся задачи создаёт следующую копию с новым сроком
   (`daily`, `weekly` по дням недели, `monthly`, `everyNDays`); сумма оценок времени за день.
2. **Парсер быстрого ввода** (`logic/quickAdd.ts`): строка → `{title, dueDate?, dueTime?, projectName?, tags[], priority, recurrence?, estimateMin?}`.
   Поддержи: `сегодня`, `завтра`, `послезавтра`, дни недели (`в пн`, `в пятницу`, `пт`),
   `через 3 дня`, `через неделю`, даты `12.11`, `12 ноября`, время `9:00`, `в 9`, `в 18:30`,
   `#проект`, `@тег`, `!1`…`!4`, `каждый день`, `каждую неделю`, `по будням`, `~30м`/`~1ч` (оценка),
   и английские `today`, `tomorrow`, `mon`…`sun`. Распознанные части убираются из названия.
   Текущая дата передаётся аргументом (для тестов). **Не меньше 25 тестов**, включая крайние случаи
   (слово «завтра» внутри названия в кавычках, прошедшая дата → следующий год, `в 9` без даты → сегодня).
   Новый проект из `#проект` создаётся, если такого нет (без учёта регистра).
3. **Интерфейс** (mobile-first, 360 px):
   - вверху поле быстрого ввода с живым предпросмотром распознанного (чипы: дата, проект, приоритет);
   - вкладки «Сегодня / Предстоящие / Входящие / Проекты»;
   - строка задачи: чекбокс, название, срок, проект, приоритет цветом; тап → редактирование
     (все поля, удаление с подтверждением); свайп или кнопка «Перенести на завтра»;
   - **адаптация**: на вкладке «Сегодня» вызови `useDailyTargets(todayKey())`, покажи полосу
     «запланировано X мин из ёмкости Y мин». Если `allowDeferLowPriority` и план превышает ёмкость —
     предложи кнопку «Перенести P3–P4 на после события»; задачи проекта `focusProjectId` подними наверх
     с пометкой «фокус»;
   - пустые состояния с подсказкой примера быстрого ввода.
4. **Компонентные тесты**: добавление через быстрый ввод, выполнение, перенос, повторяющаяся задача.

## Готово, когда
`npm run check` зелёный; `docs/progress/tasks.md` заполнен (сделано / не сделано / решения);
изменения в push, открыт PR в `main` с чек-листом пунктов выше.
